# 投资环境

`navigate` 展示三项投资环境，AI 使用 `act environment --option N` 选择。点击前读取指定卡标题；标题漏读时停止输入。普通选项确认后等待四秒并点击左下角，后续画面由 AI 核对。

2026-11-28 实机选择「蓝海」后，先显示单张随机环境「特权阶级」，再次点击底部「确认」才进入备战。程序在蓝海首次确认后读取标题、中央卡片文字和居中的确认按钮；现场三卡页面的确认按钮偏右。确认单卡页面后使用 Pipeline 点击一次并等待备战标题；四秒后仍未确认单卡或 Pipeline 失败时返回截图和待核对状态，不重复输入。返回 `input_sent`、`random_environment` 文字及 Pipeline 节点详情。其他随机环境及修改后的完整游戏内流程待实机验证。
