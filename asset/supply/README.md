# 补给页面模板

来自用户 2026-11-16 提供的补给截图 `pebrel-paste-6k7E0t.png`。原图 1917×1078，使用 Pillow LANCZOS 缩放到 1920×1080 后裁切，完整归一化样例保存在 `test/fixtures/supply/five-options.png`。

以下为左、上、右、下裁切框：

| 文件 | 裁切框 | 用途 |
|---|---|---|
| `title.png` | `(909, 142, 1010, 172)` | 中央「补给阶段」标题 |
| `trial.png` | `(335, 363, 379, 390)` | 红色「试用」标签 |
| `refresh.png` | `(1298, 968, 1335, 1004)` | 底部圆形刷新按钮 |
| `refresh_disabled.png` | `(1298, 968, 1335, 1004)` | 2026-11-16 实机 3-3 原始截图中的零次灰色刷新按钮 |

标题阈值为 0.85，试用标签和两种刷新外观均为 0.9。实机原始 1920×1080 标题对归一化模板的分数为 0.889，四张备战与主角选择保存帧为 0～0.196，据此调整标题阈值。没有刷新按钮是用户确认存在的页面变化；其他外观待补样例。
