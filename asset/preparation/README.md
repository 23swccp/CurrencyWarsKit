区域坐标见 `tools/game/slots.py`，模板按原始亮度保存。

备战标题使用一次局部 OCR，按实际文字框坐标区分商店收起与展开，同时读取节点。`shop.png`、`icons.png`、`shop_open.png` 用于辅助确认，阈值为 0.9。右侧行动按钮读取 OCR 文字并按已知动作映射分流。
